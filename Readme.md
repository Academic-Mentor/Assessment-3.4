# FrameFinder

FrameFinder is a simple, responsive image-search app built using HTML, CSS, and JavaScript. It will allow users to search for images by entering a topic.

## Features

- Search input with a Search button
- Category suggestion buttons for quick inspiration
- Empty-state message when no images are displayed
- Responsive CSS Grid layout for image results

## Design Decisions

- I chose a blue-and-white color theme to create a clean and simple interface.
- I added category buttons to give users ideas about what they can search for.
- I used CSS Grid so image cards can adjust to different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies or build tools are required.
